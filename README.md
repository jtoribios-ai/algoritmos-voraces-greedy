# Práctica: Algoritmos Voraces (Greedy)
Repositorio que contiene las soluciones implementadas en Java para los problemas de optimización utilizando la estrategia de Algoritmos Voraces (Greedy).

## Integrantes / Autor
- Joselyn Ariana Toribio Saloma

## Estructura del Proyecto
- `src/MochilaFraccional.java`: Solución para el problema de la Mochila Fraccional utilizando densidad de valor (Valor/Peso).
- `src/CoberturaAntenas.java`: Solución para el problema de Cobertura de Antenas Wi-Fi en líneas rectas.

## Cómo Ejecutar los Programas
Asegúrate de tener instalado **Java JDK** en tu computadora.

1. Compilar los archivos fuente:
   ```bash
   javac src/MochilaFraccional.java
   javac src/CoberturaAntenas.java
